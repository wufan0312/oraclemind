|----|------|------|-------------|------|

- env 文件已出库（本地保留，面板补齐）；改 env 必须手动 Redeploy。
- 历法口径：命理类走农历（八字/大运/流年/生肖/灵数/紫微），西方占星（本命盘、真太阳时 EoT）走公历；农历换算单一来源 `@/lib/lunar.ts`。
- 存档类 persist 必须以 ref 为权威快照并立即回写（防同事件多次 persist 覆盖丢数据）。
